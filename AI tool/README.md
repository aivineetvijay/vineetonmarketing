# AI tool

AI tools built for marketers. Each tool lives in its own folder here.

## Adding a tool

1. Create a folder named after the tool, in lowercase with hyphens, e.g. `seo-brief-builder/`.
2. Put the tool's files inside it.
3. Add a short `README.md` in that folder covering:
   - **What it does** — one or two sentences.
   - **Who it's for** and the problem it solves.
   - **How to use it** — steps, inputs and outputs.
   - **Status** — Live, Beta or Coming soon (matches the AI Tools page on the website).
